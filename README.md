# Password Generator

Generates secure random passwords with options for length, letters, numbers and symbols.

Built with plain **HTML, CSS and JavaScript**. No libraries, no build step.

## How to run

Download or clone this repo and open `index.html` in your browser.

```bash
git clone https://github.com/Ddharsh1707/password-generator.git
```
